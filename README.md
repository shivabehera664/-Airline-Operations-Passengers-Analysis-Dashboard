**✈️ Airline Operations & Passengers Analysis Dashboard**-


An Interactive Power BI Dashboard Analyse 1.5M+ US Domestic Flight Records (1990–2009), Covering Airline Routes, Passengers volume and Airport Traffic Trends.

📊 **Overview**
This project Explores US Domestic Flight Operations Data to Uncover Trends in Passengers traffic, flight volume and Routes Popularity Across Two Decades. The Dashboard Provides an Interactive Single-page View Combining KPI cards, Trend Charts and Geographic Route Maps.

**📁 Dataset**
Source: "Airports.csv"(Compressed as "Airports.zip")
Time span: 1990–2009
Key Fields:
Origin & Destination airports Codes and Cities,
Passengers, Seats, Flights,
Distance between Airports,
Fly date, Origin/Destination City Population,
Latitude/Longitude for Both Airports.

**🧰 Tools Used**
Power BI Desktop — Data Modelling, DAX ,visualization.
Power Query — Data Cleaning and Transformation.

**📈 Dashboard Features**
KPI Cards — Total Passengers, Distances and Flights. 
Clustered Column Charts — Passenger/Flight Volume by Category.
Area & Line Charts — Traffic Trends Over Time (1990–2009).
Interactive Slicers — Filter by Fly Date ,Origin City and Destination City. 
Map Visuals — Geographic View of Origin and Destination Airports.
Buttons — Use Bookmarks to Control Visuals When Requires.
